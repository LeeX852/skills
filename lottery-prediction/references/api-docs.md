# 大乐透数据源API文档

## 概述

本文档记录了大乐透历史数据获取的各种在线数据源及其API接口信息。

## 数据源列表

### 1. 500彩票网

**网址**: https://datachart.500.com/dlt/

**特点**:
- 数据完整性好，包含历史所有期次
- 更新及时，通常在开奖后立即更新
- 提供多种筛选和统计功能
- 免费访问，无需API密钥

**数据格式**: HTML页面

**关键URL**:
- 历史数据: `https://datachart.500.com/dlt/history/newinc/history.php?start={}&end={}`
- start: 起始期次（0表示最新）
- end: 结束期次（获取期数）

**解析方法**:
使用正则表达式从HTML中提取数据

```html
<tr>
  <td>期号</td>
  <td>开奖日期</td>
  <td>前区号码1</td>
  <td>前区号码2</td>
  ...
  <td>后区号码1</td>
  <td>后区号码2</td>
</tr>
```

### 2. 网易彩票

**网址**: https://caipiao.163.com/

**特点**:
- 数据可靠，网易官方维护
- 提供详细的统计数据和分析
- 界面友好，易于导航

**数据格式**: 可能是JSON或HTML

**关键URL**:
- 历史数据: `https://caipiao.163.com/award/dlt/{start}/{end}`
- start: 起始期号
- end: 结束期号

### 3. 新浪彩票

**网址**: https://lottery.sina.com.cn/

**特点**:
- 新浪官方数据源
- 数据更新及时
- 提供多种彩票数据

**数据格式**: JavaScript文件（JSONP）

**关键URL**:
- 历史数据: `https://lottery.sina.com.cn/award/dlt/data.js`

**数据格式示例**:
```javascript
[
  {
    "expect": "2026001",      // 期号
    "opentime": "2026-01-01", // 开奖日期
    "red_ball": [1,2,3,4,5],  // 前区号码
    "blue_ball": [1,2]        // 后区号码
  },
  ...
]
```

### 4. 中国体育彩票官方网站

**网址**: https://www.lottery.gov.cn/

**特点**:
- 官方权威数据源
- 最准确的开奖结果
- 可能需要特殊的访问方式

**注意**: 官方网站可能限制爬虫访问，建议使用其他数据源。

## 数据格式规范

### 开奖数据结构

```json
{
  "period": "2026001",           // 期号，YYYYXXX格式
  "date": "2026-01-01",          // 开奖日期，YYYY-MM-DD格式
  "front": [1, 8, 15, 22, 29],   // 前区号码，5个，范围1-35
  "back": [3, 9]                 // 后区号码，2个，范围1-12
}
```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| period | string | 期号 | "2026001" |
| date | string | 开奖日期 | "2026-01-01" |
| front | array | 前区号码 | [1, 8, 15, 22, 29] |
| back | array | 后区号码 | [3, 9] |

## 数据获取注意事项

### 1. 请求频率限制
- 避免过于频繁的请求
- 建议每次请求间隔至少1秒
- 使用缓存机制减少重复请求

### 2. 异常处理
- 网络连接超时
- 数据格式变化
- 服务器维护
- IP被限制

### 3. 数据验证
- 验证期号格式
- 验证号码范围
- 验证号码数量
- 验证号码不重复

### 4. 用户体验优化
- 提供进度提示
- 支持取消操作
- 缓存常用数据
- 离线模式支持

## 备用方案

当所有在线数据源都不可用时，可以考虑：

1. **本地缓存数据**
   - 使用之前获取并保存的历史数据

2. **模拟数据**
   - 生成符合规则的随机数据用于演示

3. **手动导入**
   - 允许用户从文件导入历史数据

4. **用户输入**
   - 允许用户手动输入近期开奖号码
