# Godot Development Agents Index

## Overview
Specialized AI agents for different aspects of Godot Engine game development.

## Agents List

### General Development
- **[godot-developer](godot-developer.md)** - Full-stack Godot developer for all game systems

### Specialized Agents
- **[godot-2d-expert](godot-2d-expert.md)** - 2D game development specialist
- **[godot-3d-expert](godot-3d-expert.md)** - 3D game development specialist
- **[godot-ui-expert](godot-ui-expert.md)** - UI/UX design and implementation
- **[godot-ai-expert](godot-ai-expert.md)** - Game AI and NPC behavior
- **[godot-networking-expert](godot-networking-expert.md)** - Multiplayer and networking
- **[godot-optimization-expert](godot-optimization-expert.md)** - Performance optimization

## Usage

### Selecting an Agent
- Use **godot-developer** for general game development tasks
- Use specialized agents for specific domains (2D, 3D, UI, AI, etc.)

### Example Tasks

**godot-developer**:
- "Create a player character with movement and jumping"
- "Set up a game scene with enemies and collectibles"
- "Implement a save/load system"

**godot-2d-expert**:
- "Create a tilemap-based platformer level"
- "Implement parallax scrolling background"
- "Set up 2D lighting for a night scene"

**godot-3d-expert**:
- "Create a third-person camera controller"
- "Set up PBR materials for a realistic environment"
- "Implement 3D pathfinding for enemies"

**godot-ui-expert**:
- "Create a main menu with buttons"
- "Design a health bar HUD"
- "Implement an inventory system with drag-and-drop"

**godot-ai-expert**:
- "Create an enemy patrol system"
- "Implement a state machine for boss AI"
- "Design a behavior tree for complex NPC decisions"

**godot-networking-expert**:
- "Set up a multiplayer lobby"
- "Implement player synchronization"
- "Create a chat system"

**godot-optimization-expert**:
- "Profile and optimize frame rate"
- "Reduce draw calls in 3D scene"
- "Optimize for mobile devices"
